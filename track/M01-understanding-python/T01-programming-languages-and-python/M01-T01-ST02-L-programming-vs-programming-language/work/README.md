# Programming vs Programming Language

## What Is Programming?

Programming is the structured process of analyzing a problem and designing step-by-step instructions to solve it using a computer. It involves understanding the required inputs, defining the conditions or rules, planning the logical flow, and verifying that the steps produce the right outcome before writing actual code.

## What Is a Programming Language?

A programming language is a formal system of keywords, symbols, and grammatical rules that allows humans to write instructions a computer can understand and execute. Examples include Python, Java, C++, and JavaScript.

## What Is Python?

Python is one specific high-level programming language used to write and run solutions cleanly. It is a tool used during programming, not programming itself.

## What Is Syntax?

Syntax refers to the strict writing rules of a programming language—such as spelling keywords accurately, using proper capitalization, placing colons and brackets where required, and maintaining valid indentation. If syntax rules are broken, the computer cannot process the code.

## Programming and Python

Programming is the thinking and problem-solving phase where you design the logic, whereas Python is the medium used afterward to translate that logic into runnable code. A single solution designed through programming can be implemented in Python or any other programming language.

## What Remained the Same?

When moving from pseudocode to Python, the core problem, the inputs (`percentage` and `active_backlogs`), the eligibility conditions (at least 60% and 0 backlogs), the decision flow, and the expected outputs (`Eligible` or `Not Eligible`) all stayed identical.

## What Changed?

The human-readable steps were translated into Python's specific format: using lowercase keywords (`if`, `else`, `and`), comparison operators (`>=`, `==`), colons at the end of condition lines, indentation to group code blocks, and the `print()` function to display output.

## My Final Understanding

Programming helps me: break down problems into clear, logical steps before touching the keyboard.

Python helps me: express that logic in a clean language that a computer can execute.

Syntax tells me: the exact formatting and grammar rules I must follow so Python understands my instructions without errors.
